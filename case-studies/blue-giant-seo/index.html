01 / PROBLEM

イベントの情報はある。
けれど、参加の判断は難しい。

イベントに興味を持った人が必要とするのは、開催期間や会場名だけではありません。複数のチェックポイント、押印可能時間、移動経路など、参加の直前には確認すべき情報が増えます。

そこで、「イベントを知る」と「街で実際に回る」の距離を縮める情報設計を課題にしました。

検索で見つけてもらうだけでなく、現地で動ける情報へ。
02 / INSIGHT

探しているのは、
記事ではなく「次の一歩」。

「ブルージャイアント スタンプラリー」と検索する人は、概要のほかにも、何か所あるのか、どこから回るか、いつまで参加できるかを知りたい可能性があります。これを仮説として、答えを素早く確認できる記事と、条件から回り方を考える体験を分けて構築しました。

03 / EXPERIENCE

まず答える。
必要なら、ルートまでつくる。

特集記事は開催情報を整理し、6地点・押印時間・参加条件へのアクセスを容易にしました。ルート体験は出発地点、残り時間、取得済みスタンプ、押印終了時刻から巡回順を検討します。

公式のイベント情報と、仙台えらぶ！独自の判断・推定を分け、実際の徒歩経路は地図サービスで確認できるようにしています。

05 / RESULT

検索上位という事実を、
クリックまで確認する。

2026年10月15日〜11月13日のGoogleオーガニック検索クエリでは、「ブルージャイアント スタンプラリー」が42回表示され、15クリックを獲得。平均掲載順位2.57位、CTR35.71%でした。

GA4では特集記事が192ページ表示・78アクティブユーザー、ルート体験が63ページ表示・16アクティブユーザーでした。両ページの利用者には重複があり得るため、合計をユニーク人数として扱いません。

07 / APPLICATION

イベントだけでなく、
地域の商いにも。

イベントで得た知見を、そのまま他社の成果として誇張することはしません。一方、検索意図を起点にして、必要な情報を届け、来店・問い合わせ前の判断を支えるという設計手法はさまざまな業種に応用できます。

店舗・飲食

メニュー・営業時間・予約前の疑問を解消。

観光

訪問者が移動可能な行程まで設計。

地域イベント

参加条件と現地の回り方を一体化。

サービス業

検索から比較・相談への導線を改善。

LET'S BUILD

御社の情報を、
行動につながるWeb体験へ。

検索で見つけてもらうことから、利用者が迷わず選べることまで。SEO、Web制作、データ設計、計測を組み合わせて、集客導線の課題を整理します。
