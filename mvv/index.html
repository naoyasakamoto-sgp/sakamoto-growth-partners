Vision / Mission / Value

大きく目指し、
現場から動く。

Vision

世界一の時価総額企業をつくる。

目先の規模ではなく、長期で大きな企業価値を生み出すことを目指します。

地域の現場で得た知見を、仕組みとプロダクトへ変え、より広い社会へ価値を届けます。

Mission

売上を増やす。

コストを下げる。

時間を返す。

ITやAIを導入すること自体は目的にしません。経営に何が残ったかで判断します。

Value

まず動く。
完璧を待たず、できることから着手する。

最後までやる。
提案で終わらず、使われるところまで見る。

難しいを、簡単に。
ITやAIを、現場がそのまま使える言葉と形にする。

Purpose

人と企業が、より良く判断し、行動できる仕組みをつくる。
