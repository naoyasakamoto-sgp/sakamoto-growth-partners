これまでの仕事。

2023年から、要件整理、開発、AI、クラウド、業務自動化の仕事をしてきました。

要件を聞くだけでも、コードを書くただけでもなく、「何に困っているのかを整理して、実際に動くところまでつくる」のが、自分の仕事の軸です。

2023–2025　会社員時代。

生産管理システム刷新。
店舗現場へのヒアリング、As-Is / To-Be整理、要件定義、基本設計。まずは「何を作るべきか」を整理する仕事から始めました。

生成AI（RAG）ナレッジシステム。
Vue / TypeScript、FastAPI / Laravel、OpenAI API、FAISS、AWSを使い、要件整理から実装・運用まで担当。社内計測で一次回答率80%まで改善しました。

生成AI 議事録アプリ。
Go、OpenAI API、AWS、Terraformを使い、API・DB・インフラを担当。PoC期間中、商談議事録の作成時間を80%削減しました（社内計測）。

業務自動化RPA。
Python / Seleniumを中心に、不動産契約書作成業務の自動化を担当。要件整理、実装、テスト、運用改善、進捗・品質管理まで見ました。

2025–2026　個人事業主時代。

AIエージェントPoC。
スタートアップの少人数チームで、React / TypeScript、Go、Python、Azureを使い、UIからAPI、AI連携、クラウドまで横断して実装しました。

大規模AIプロダクトの品質・テスト設計。
約60名規模のプロジェクトで、テスト設計、Zephyr運用、Jiraでの進捗・課題管理、会議体運営を担当しました。

大手通信事業者向けAIプラットフォーム。
約40名規模のチームで、React、Hono.js、PostgreSQL / pgvector、OpenSearch、Azure OpenAI、Vertex AI、AWSを扱い、フロントからAI・検索・BFFまで横断して開発しました。

2026–　合同会社SGP。

仙台・一番町を拠点に、中小企業向けの社外IT担当として、IT・AI・業務改善を相談から実装まで直接見ています。
